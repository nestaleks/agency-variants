## Typography

- **Display:** classic transitional serif in *italic* (Times-like; looks like Times New Roman Italic / similar). Used for "Proyectos que transforman espacios" and chapter titles; chapter headers in italic small-caps-like uppercase. Suggested web alternatives: *Cormorant Garamond* italic (more refined) or *Playfair Display* italic.
- **Body / headings:** humanist sans, semibold headings (looks like Open Sans / Calibri family). Web alternative: *Open Sans* or *Jost* (already on site).
- Justified body text with hyphenation; line-height ≈ 1.35; no tracking on body; no technical/numeric typography (catalog contains **no** specifications, prices, or areas).

## Layout and composition

- Portrait A4-like pages with a fixed system: dark-green **diagonal corner panel** top-left (logo) or bottom-right (logo) with a **thin gold curved line** running parallel to the edge.
- Images cropped by large **soft S-curve waves** (rounded diagonal clip shapes) — the single most recognizable graphic device.
- Ivory/blush wave bands layered behind text.
- Text blocks bottom-left, generous margins, low density (1 headline + 1 paragraph per page).
- Two-image pages alternate top-right/bottom-left crops.
- Botanical line illustration (gold palm/olive leaves) on cover bottom-left.

## Brand characteristics supported by evidence

- Mediterranean premium residential, boutique scale (7–9 units per building) — explicit.
- Experience/reliability: "Desde 2018", "más de 7 años", "riguroso control de calidad en cada etapa" — explicit.
- Lifestyle & wellbeing: pillars "Arquitectura contemporánea / Calidad que perdura / Bienestar en cada espacio".
- Location intelligence: maps, distances (30 m to El Arenal, 10 min to beach).
- Investment orientation: closing line about "su próxima gran inversión".
- **Not** supported: luxury ultra-high-end, technological innovation claims beyond generic text, awards, client numbers.

## Deliverables

1. **Strongest characteristics:** dark green + gold + ivory palette; italic serif headlines; wave/diagonal image masks; calm, airy pages; strong real photography/renders.
2. **Positioning:** boutique Mediterranean developer — "Experiencia que construye confort".
3. **Recommended:** colors above; Cormorant Garamond (italic) + Open Sans/Jost.
4. **Graphics for web:** diagonal green corner, thin gold keyline, S-curve image masks (SVG clip-path), gold botanical line art (recreate as simple SVG, sparingly).
5. **Print-only:** stacked wave bands on every page (too heavy on long scroll), justified hyphenated text (poor on screens), Google-Maps screenshots (replace with links / live description).
6. **Conflicts with existing assets:** site logo PNG is **cyan #04C3E2 + black**; catalog uses gold monochrome logo. Solution: non-destructive CSS `mask-image` recolor of `images/logo2.png` (full mark) to gold/ivory/charcoal. Site primary color teal `#237385` and Poppins conflict with catalog — replaced in concepts.
7. **Opportunities:** catalog is far more premium than the website; website has the data the catalog lacks (unit areas, bedrooms, plans) → combine catalog emotion with web data.
8. **Uncertainties:** exact fonts and HEX are approximations; catalog is Spanish only; Foners unit count not stated in catalog (website lists 4 apartments); whether S'Olivar/Boho Corner are sold is stated only on the website ("SOLD" badge).
